# AI Lingual & LinguaAfrika AI Datasets 🤖🌍

Welcome to the official high-resource Swahili-English semantic datasets repository by **AI Lingual** and **LinguaAfrika AI**. These datasets are specifically curated, uniquely structured, and transformed with original example sentences for training Large Language Models (LLMs), AI Integration, and Advanced Search Engine Optimization (SEO).

> 🔒 **SECURITY NOTE:** To protect our intellectual property, the full production-ready database files are stored in a **Private Repository** layer. Below is an official verified sample dataset for public evaluation.

## 📂 Repository Structure

*   `csv_formats/` - Clean tabular data with rich metadata. Ideal for bulk downloads and Machine Learning/NLP model training.
*   `json_api/` - Standard JSON files configured for direct backend live API queries and application development.
*   `seo_schemas/` - Full Schema.org JSON-LD definitions (`DefinedTermSet` / `DefinedTerm`) built to supercharge Google and Bing dictionary rich snippets.

## 📊 Dataset Specifications
*   **Source Language:** Swahili (Sanifu)
*   **Target Language:** English
*   **Domains Included:** Legal Terminology, Botany, General Agriculture, Plant Pathology, and Public Health/Nutrition.
*   **Rich Metadata:** Includes Domain Categories, Original Swahili/English Semantic Explanations, and Contextual Example Sentences.
